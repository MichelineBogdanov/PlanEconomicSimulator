# PlanEconomicSimulator

Симулятор плановой экономики: подготовка пятилетки, автоматическое исполнение,
потребности населения, производственные цепочки и варианты действий при отклонениях.

Unity **6000.6.0f1**, C#, Windows x64. Сейчас доступен технический каркас;
игровая экономика ещё не реализована.

- [Спецификация](SPEC.md)
- [Правила разработки](AGENTS.md)
- [Визуальное направление](DESIGN.md)
- [Окружение, тесты и CI/CD](docs/DEVELOPMENT.md)

Откройте корень проекта через Unity Hub с закреплённой версией редактора.
Для CLI закройте редактор этого проекта и выполните:

```powershell
./scripts/Invoke-Unity.ps1 -Task EditMode
./scripts/Invoke-Unity.ps1 -Task PlayMode
./scripts/Invoke-Unity.ps1 -Task Build
```

Review и merge выполняет владелец репозитория. CI требует отдельной настройки Unity-лицензии;
инструкции и ограничения описаны в руководстве разработки.
